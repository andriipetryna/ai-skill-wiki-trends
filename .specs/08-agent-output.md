# 08 — Agent-facing output: findings, caveats, answer checklist, final report

## Why
After 01–07 the JSON contains many correct numbers, but a cheap model (Haiku) still makes mistakes at the answering step. Observed in runs of an earlier version:
- Haiku computed ratios itself from raw views ("Polish readers view it 2.3× more") — an invented number and a wrong conclusion;
- it wrote "views per million **residents**";
- when it produced a PDF, it shortened the chat answer and dropped the caveats and the file path.

General rules in `SKILL.md` are often ignored at that step. A **concrete list next to the data**, generated by code for this exact result, is followed. So the code emits:
- `findings` — ready-made sentences containing all the numbers;
- `caveats` — data-dependent caveats;
- `answerChecklist` — what the answer must contain.

## Scope
- **In:**
  - `scripts/src/text.ts` (en/uk);
  - the `findings`, `caveats`, `answerChecklist` fields;
  - the final PDF layout;
  - a rewrite of `SKILL.md`'s answer rules.
- **Out:** metric changes.

## Code changes

### `scripts/src/text.ts` (new)
All human-facing language in one place: `type UiLang = "en" | "uk"`. Move the report's `LABELS` here.

**1. Formatting and translation:** `tVerdict(v, lang)`, `tLevel(level, lang)`, `signed(x)` (`+12.3%` / `-4.5%` / `n/a`), `pfmt(p)` (`p<0.001` or `p=0.123`), `int(x)` (`12,345`).

**2. `buildFindings(result, lang): string[]`** — sentences in this order:

a. One per language, in `--langs` order:
   - `ok`:
     - en: `{lang}: {verdict} — share of edition traffic {signed(trend)}/yr ({pfmt}), YoY {signed(yoy.sharePct)}, median {int} views/month; confidence {level}.`
     - uk: `{lang}: {вердикт} — частка переглядів {…}/рік ({pfmt}), рік-до-року {…}, медіана {…} переглядів/міс; довіра {рівень}.`
   - `no_article`: en `{lang}: no article on this topic.` / uk `{lang}: статті на цю тему немає.` If `suggestions` exist, append en `Closest: «A», «B».` / uk `Найближчі: «A», «B».`
   - `no_data`: en `{lang}: no pageview data.` / uk `{lang}: немає даних про перегляди.`

b. If ≥ 2 languages have metrics — relative interest, sorted by `sharePerMillion.last12Avg` desc:
   - en: `Relative interest (article views per million pageviews of the edition, not per million people; last 12 months): uk 169.37, hu 59.62. Raw views are not comparable across languages.`
   - uk: the same content.

c. If `ranking.length ≥ 2`: the order line with weights (format from 07).

d. For every language with `|trend.editionPctPerYear| ≥ 10`:
   - en: `{lang}.wikipedia overall traffic changes {signed}/yr (raw article views {signed}/yr), so share is the fairer measure.`
   - uk: the same content.

**3. Caveats** — structured `{ code, params? }`, rendered with `renderCaveat(c, lang)`. Codes and conditions:

| code | When | en text |
|---|---|---|
| `interest_not_demand` | always | Pageviews measure curiosity and attention, not willingness to pay. Treat results as a signal for further validation. |
| `share_normalisation` | always | Trend = change in the topic's share of all pageviews of that edition (views per million pageviews, not per million people); spikes are removed first. |
| `period` | always | Complete months only: {from} – {to}. |
| `short_period` | < 24 months | Period is shorter than 24 months: seasonality is not controlled. |
| `search_resolved` | `matchedBy = search` | "{input}" was matched via search to "{label}" ({qid}). Alternatives: {…}. |
| `missing_articles` | a topic lacks an article in some languages | No article for "{topic}" in: {langs}. Missing coverage may itself signal low interest. |
| `manual_article` | `--article` used | For {lang} the article was chosen manually: "{title}". |
| `redirects_on` / `redirects_off` | from 02 | (see 02) |
| `single_article` | one topic and no `--article` | A single article is a proxy for the topic. |
| `cross_language` | > 1 language | Views per million compare relative interest across editions; absolute volume reflects the edition's audience size, not the market size. |
| `bots` | always | Only agent=user traffic. Known bots are excluded, but some automated traffic may remain. |

Ukrainian texts carry the same content. Move them over from `caveatList` in `report.ts` and extend.

**4. `buildAnswerChecklist(result, reportPath): string[]`** (English, for the agent):
1. **If there is a report, this item goes first** (weak models drop the tail of long lists): `Write the full PDF path in your reply: {path}. The reply must still contain the full answer below; the PDF does not replace it.` Keep any existing chart/PNG instruction from the current SKILL.md step 5 as its own item right after this one.
2. `Start with a one-sentence direct answer to the user's question, in the user's language.`
3. `Summarise every language: verdict, trend.sharePctPerYear, confidence level. Copy numbers from this JSON, never compute new ones.`
4. For every `matchedBy = search`: `Say the topic "{input}" was matched via search to "{label}"; offer alternatives: {…}.`
5. If any `low`: `Say clearly that confidence is LOW for: {lang} ({first "-" reason}); …`
6. If any spikes: `Mention one-off spikes (excluded from the trend): {lang} {months}; …`
7. If any `no_article`: `Mention languages without an article: {langs}. Show their suggestions and offer --article; never pick one silently.`
8. If > 1 language: `Compare languages only by sharePerMillion or the 'Relative interest' finding, never by raw views or ratios.`
9. If `ranking.length ≥ 2`: `Give the ranking, state the weights used and offer to change them.`
10. Always: `Include the caveat that pageviews show interest, not willingness to pay, plus at least one more caveat from caveats.`

### `scripts/src/cli.ts`
`analyze` output:

```jsonc
{
  "ok": true, "query": {...}, "resolution": [...], "perLanguage": [...], "ranking": [...],
  "findings": ["..."],        // en
  "answerChecklist": ["..."], // en
  "caveats": ["..."],         // en, rendered
  "files": { ... }            // unchanged: data, chart (svg), png, report
}
```

`data.json` stores the structured `caveats` (codes), so the report can render them in any language.

### `scripts/src/report.ts` — final A4 layout, one page
1. Title (16 pt bold) and meta line (8 pt): languages, period, date.
2. **Key findings:** `buildFindings(…, reportLang)`, up to 9 items, 8.8 pt.
3. **Chart** of share with spike rings. Adaptive height so everything fits on one page: 270 pt with ≤ 4 findings, 235 pt with 5–6, 200 pt with > 6.
4. **Table** by `rank`: Lang | Article | Views/mo (median) | Per million | YoY share | Trend/yr | p | Verdict | Confidence. 8 pt; widths sum to 523 pt; the language code in its series colour.
5. **Interpretation** (`--notes`), if given: labelled "written by the AI agent", up to 600 characters.
6. **Assumptions & limitations:** `renderCaveat` in the report language, as many as fit. Overflow must never push content to a second page.
7. Footer: data source, "rings = spike months excluded from trend".

**Important** (already handled in the MVP, do not break): svg-to-pdfkit sizes an SVG by its root `width`/`height` attributes, so they must be stripped before embedding, keeping only the `viewBox`.

### `SKILL.md` — rewrite "Rules for the answer"

```markdown
## Rules for the answer

**Work through `answerChecklist` from the output, item by item.** It is generated for this exact result. Also:

- Every number you state must appear in the JSON. Copy it exactly; never recompute, estimate or compute ratios. `findings` has ready-made sentences — paraphrase them in the user's language.
- The headline metric is `trend.sharePctPerYear` (growth of the topic's share of the edition's traffic). Mention `viewsPctPerYear` only when it differs in direction or a lot; `editionPctPerYear` explains why.
- `verdict`: growing/declining = significant (p < 0.1) and beyond ±5%/yr; flat = within ±5%/yr; inconclusive = large but not reliable. Never upgrade "inconclusive".
- Trust question → `confidence.level` + `reasons`. For `low`, say the data does not support a conclusion.
- Never compare raw view counts between languages. Views per million = per million pageviews of the edition, not per million people.
- If `spikes` is non-empty, name the months (one-off events, excluded from the trend).
- `ranking` is relative to the compared languages and weights; state the weights, offer to change them.
- Include at least two `caveats`, one of them: pageviews show interest, not willingness to pay.
- Keep it short: direct answer → per language → caveats → one next step.
```

Keep the existing step that tells the agent to show the chart PNG and link the PDF. Also update the examples table and the field descriptions.

Move the detailed methodology to `references/methodology.md`: the agent reads it only when the user asks. It is a condensed version of specs 01–07 with formulas and thresholds.
